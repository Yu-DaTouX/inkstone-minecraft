# Inkstone Minecraft 0.3.0

新增 LittleSkin 和其他兼容 authlib-injector 的皮肤站登录。

- **外置登录**：在启动页「添加账号」或「设置 → 账号」登录，默认使用 LittleSkin，也可填写其他兼容站点的 HTTPS 地址。账号有多个角色时可以选择。凭据由系统加密保存，启动前验证或刷新会话；首次启动自动下载并校验 authlib-injector。
- **界面修正**：修正窄窗口下的 Mod 列表布局，简化删除提示，不再在进度中显示资源哈希。

已用真实 LittleSkin 账号登录、启动 Minecraft 1.21.1，并进入启用 LittleSkin 在线验证的测试服务器。旧版 Minecraft 和各加载器的兼容性未逐一实测。

下载 Windows x64 安装包 `Inkstone-Minecraft-Setup-0.3.0.exe`。`.blockmap` 和 `latest.yml` 供启动器自动更新使用。

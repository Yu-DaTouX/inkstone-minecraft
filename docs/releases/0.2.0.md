# Inkstone Minecraft 0.2.0

新增微软正版登录、Mod 目录自动刷新，并改进启动性能、Mod 文件操作和崩溃诊断。

- **微软正版登录**：在启动页添加账号或「设置 → 账号」使用微软设备码登录。检查 Minecraft Java 版授权及玩家档案，加密保存刷新凭据，启动前刷新会话。PCL 迁移的正版账号需要重新登录一次。
- **Mod 目录自动刷新**：外部添加、删除、替换 Mod 或改名启停后自动更新列表；删除整个目录后重建也能恢复监听。
- **启动性能**：按 Java 版本选择保守 JVM 默认参数，尊重手动设置；内存建议只在用户确认后应用到当前版本，并支持恢复。移除对其他进程的内存整理，减少后台装饰重绘和日志刷新开销。
- **Mod 操作保护**：加强前置依赖版本检查、下载校验、文件替换及失败回滚；游戏运行或任务占用目录时阻止冲突修改。
- **崩溃诊断**：改善原因说明与修复入口，区分 Java 堆内存不足和原生内存不足，增加 JVM 参数冲突检查与下载错误提示。

验证包括完整自动化测试、类型检查、Windows 安装包构建及更新文件校验。微软应用配置和真实设备码获取已验证；真实账号授权后进入游戏及从旧版本安装更新的完整过程仍需实际使用验证。

下载 Windows x64 安装包 `Inkstone-Minecraft-Setup-0.2.0.exe`。`.blockmap` 和 `latest.yml` 用于启动器自动更新。
